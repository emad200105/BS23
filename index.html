What the fix changes

  • Session: a long-lived refresh token in secure storage renews the session silently. The app logs out only when the server rejects the token, never on a timeout or offline.
  • Address: delivered addresses are saved to the account, not only the phone. The last-used one is pre-selected, and the app asks only when GPS shows the user is somewhere else.
